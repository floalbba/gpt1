# Заказы клиента через MCP

Полный диалог с клиентом — в `doc/Промпт_Заказ.md`. Ниже — когда вызывать инструменты и что делать при ошибках.

## Правила идентификаторов

- Передавай **наименование, код или артикул**. Не передавай и не показывай GUID.
- Партнёра не передавай: его 1С берёт из контрагента (`counterparty_name`).
- Заказ после создания адресуй полем `number` (`order_number`), не `order_ref`.

## Когда вызывать

| Ситуация | Инструмент |
|---|---|
| Нужно проверить или уточнить покупателя | `partners_search` |
| Пользователь назвал товар | `nomenclature_search` |
| Сводка подтверждена («да») | `order_create` |
| Заказ создан, errors пуст | `order_post` (`post=true`) |
| Посмотреть уже созданный заказ | `order_get` |
| Изменить созданный заказ | `order_update` |

Не вызывай `order_create` до подтверждения сводки. Не вызывай создание при «отмена».

## Поиск

- 0 результатов — попроси уточнить, повтори поиск.
- 1 результат — возьми `code` / `article` (для клиента — `counterparty_name`).
- Несколько строк `partners_search`: если есть ровно один `kind=counterparty` с нужным именем — его и бери; строки `partner` с тем же именем не неоднозначность.
- 2+ разных товара / контрагента — покажи до 5 строк, спроси номер.

`nomenclature_search`: `query`, `counterparty_name`, `organization_name`.

## Создание и проведение

```
order_create:
  counterparty_name, organization_name, warehouse_name, delivery_date,
  items: [{ nomenclature_code, quantity, price }]

order_post:
  order_number, post=true
```

Цену бери из поиска — она по виду цен соглашения (`price_type`). Не подставляй цену другого вида цен.
В сводке по каждой строке: НДС, Всего без НДС и Всего с НДС.
Числа выравнивай по правому краю, колонки сумм не уже 10 знаков.
В итогах — скидка, сумма НДС, Всего без НДС и Всего с НДС (сверка: сумма строк = итог).
После создания заказа бери из ответа: `discount_amount`, `vat_amount`,
Всего с НДС = `amount`, Всего без НДС = `amount` − `vat_amount`;
построчно `items[].vat_amount`, `items[].amount_with_vat`.

## Ошибки

В `errors[]` смотри `message` (пользователю) и `hint` (тебе).

| Сигнал | Действие |
|---|---|
| Контрагент не найден / несколько | `partners_search`, затем `name` или ИНН |
| Товар не найден / несколько | `nomenclature_search`, затем `code` или `article` |
| Заказ не найден | `order_number` из последнего `order_create` |
| Проведение не удалось | покажи `message`; заказ уже создан |
| `ALREADY_POSTED` | `order_post` с `post=false`, затем снова провести |

После ошибки создания спроси: «Попробовать ещё раз?»
